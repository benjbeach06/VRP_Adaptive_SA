# Six-parameter time-based tune, 2026-08-23

47-trial, 8h Optuna/TPE search, n=500 capacity 400, 5 seeds x 120s per trial. First search over
the rebuilt time-based schedule (`SimAnn_VRP_Solver.py`, commit `4aaf2c3`) -- weight decay,
cooling and plateau detection all moved from iterations to wall-clock seconds, so nothing about
the old iteration-based flatness arguments was assumed to still hold. All six live
schedule/selection parameters searched together, per instruction, rather than a subset held
fixed on a self-damping argument measured under the old mechanism.

## Result

Reference (hand defaults) scored 1910.80. Best trial (28) scored **0.9845** -- 1.55% better than
defaults.

`tools/pick_tuned_center.py` picked the point actually used going forward: never the argmin
(a single best trial in a noisy search is disproportionately likely to be a lucky draw), instead
the real trial nearest the per-parameter log-space median of the top-20% bucket. That point
(`2026-08-23_chosen_center.json`) happened to coincide with trial 28 here. A second, synthetic
bucket-median blend -- untested as a combination until the grounding ablation -- was also written
(`2026-08-23_computed_center.json`).

**Grounding ablation** ([../ablations/2026-08-23_tuned_vs_stage1/README.md](../ablations/2026-08-23_tuned_vs_stage1/README.md)): 3 arms,
15 paired seeds x 300s, against the scoring rework's stage-1 commit (`c539a1e`). Both tuned points
beat it decisively -- chosen -59.63 +/- 6.48 (-9.2 sigma), computed -57.49 +/- 5.77 (-10.0 sigma),
15/15 seeds won each, indistinguishable from each other. `ReorderShortSpanExactly`'s clock share
fell from 48.79% to about 4.6%.

A single 60s run under the chosen point reached **1883.01** (Hexaly is 1861.41 at 60s, a 1.16%
gap) -- not saved to `solutions/`, so it is not rebuildable or re-verifiable.

**Superseded, not repeated, by the time-robust follow-up:** [2026-08-26_time_robust.md](2026-08-26_time_robust.md)
started from `chosen_center` and searched whether it holds across runtimes 60-300s. It does --
nothing there beat this search's chosen point.

Files: `2026-08-23_six_param_time_based.json` (all 47 trials), `.log` (run stdout),
`2026-08-23_chosen_center.json`, `2026-08-23_computed_center.json`. Generated by `tools/tune.py`
and `tools/pick_tuned_center.py`.
